## Как обновляется сайт

Страница агента = шапка страницы сайта (до `<title>`: иконки, заменитель скачивания для сайта, у Карусельной — скрытие анализа канала, у Натальи — вставка жирного) + сборка агента начиная с `<title>`. При обновлении заменяется только часть с `<title>` и дальше.
